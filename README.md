# ziweiyaluchart-dist-apply：原始碼申請入口 ／ Source code access requests

**中文**

這個 repo 只是申請入口，**不含任何程式碼**。

[chart.ziweiyalu.com](https://chart.ziweiyalu.com) 紫微斗數排盤 web app 的原始碼放在私有 repo `ziweiyaluchart-dist`，目前採邀請制，授權為 MIT。

本專案與 AI（Claude）協作開發。

**怎麼申請**

1. 登入你的 GitHub 帳號（沒有的話先到 github.com 免費註冊）
2. 到這個 repo 的 **Issues → New issue → 申請原始碼存取 Request access**，填寫並送出
3. 原作者審核通過後，GitHub 會寄邀請信到你帳號的信箱；接受邀請後就能閱讀、下載與 fork（唯讀）

**請注意**

- ⚠️ **申請內容是公開的**，任何人都看得到。請不要寫電話、Email、地址等個人資料，也**不要放任何人的出生年月日時**
- 審核完成後，原作者會在 Issue 留言並關閉，必要時會刪除該 Issue
- 只是想排盤的話，不需要原始碼，直接使用 [chart.ziweiyalu.com](https://chart.ziweiyalu.com) 就好
- 說明頁：[chart.ziweiyalu.com/ziweiyaluchart-dist/](https://chart.ziweiyalu.com/ziweiyaluchart-dist/)

**English**

This repository is only the entry point for access requests. **It contains no code.**

The source code of [chart.ziweiyalu.com](https://chart.ziweiyalu.com), a Zi Wei Dou Shu chart web app, lives in the private repository `ziweiyaluchart-dist`. Access is by invitation, and the code is MIT-licensed.

Built in collaboration with AI (Claude).

**How to request access**

1. Sign in to GitHub (create a free account at github.com if you don't have one)
2. Go to **Issues → New issue → 申請原始碼存取 Request access** in this repository, fill in the form and submit it
3. Once approved, GitHub will email an invitation to your account. After accepting it you can read, download, and fork the code (read-only)

**Please note**

- ⚠️ **Requests are public.** Anyone can read them. Don't include phone numbers, emails, addresses, or **anyone's birth date and time**
- After review, the author will reply and close the issue, and may delete it
- If you only want to cast charts, you don't need the source code — just use [chart.ziweiyalu.com](https://chart.ziweiyalu.com)
- Overview page: [chart.ziweiyalu.com/ziweiyaluchart-dist/](https://chart.ziweiyalu.com/ziweiyaluchart-dist/)
